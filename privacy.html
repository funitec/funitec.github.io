DiSMoDesk プライバシーポリシー

利用者

DiSMoDesk は開発者本人のみが利用する個人用アプリです。

取得する情報と用途

Google アカウントの許可に基づき、開発者自身の Gmail を読み取り専用で参照し、新着メールの通知にのみ使用します。メールの送信・変更・削除は行いません。

保存と第三者提供

認証情報と取得したデータは開発者が管理するマシン内にのみ保存し、第三者へ提供・販売しません。Google API から取得したデータの利用は Google API Services User Data Policy (Limited Use 要件を含む) に従います。

削除

Google アカウントの「サードパーティ製のアプリとサービス」からいつでもアクセス権を取り消せます。
